# Chisimba canvases archive

This repository preserves historical Chisimba skins and canvases. It is not
part of the active Chisimba Revival presentation runtime.

The current runtime has one supported skin, `chisimba-reborn`. Its `_default`,
`chisimba`, and `kenga-learn` canvases live with that skin in the framework
repository and contain branding/layout overrides only.

`legacy-framework-skins/` contains the old selectable skins removed from the
framework in August 2026. They are retained solely for historical reference
and must not be installed or copied into a production release.
